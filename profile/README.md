### 🧰 Drop into any stack

<table>
<tr>
<td width="50%" valign="top">

#### 🔄 [django-cqrs](https://github.com/cloudblue/django-cqrs)

Keep Django microservices in sync. Save a model once and every replica follows, over RabbitMQ or Kombu.

```sh
pip install django-cqrs
```

</td>
<td width="50%" valign="top">

#### 🔎 [django-rql](https://github.com/cloudblue/django-rql)

Give your API a query language that fits in a URL. Also for [Python](https://github.com/cloudblue/lib-rql), [JavaScript](https://github.com/cloudblue/javascript-rql) and [MongoEngine](https://github.com/cloudblue/django-mongoengine-rql).

```
?and(eq(status,active),ge(price,100))
```

</td>
</tr>
<tr>
<td width="50%" valign="top">

#### ⚡️ [chaperone](https://github.com/cloudblue/chaperone)

Fast egress proxy in Go. It adds credentials to outgoing API calls at the edge, so secrets never leave your infrastructure.

</td>
<td width="50%" valign="top">

#### 🔌 [django-postgresql-reconnect](https://github.com/cloudblue/django-postgresql-reconnect)

Database blinked? Django reconnects on its own, instead of failing every request until the workers restart.

</td>
</tr>
</table>

Also in the box: [kong-to-waf](https://github.com/cloudblue/kong-to-waf) makes Kong Gateway check every request with your WAF first, then block or log what it flags.

### 🚀 Build on CloudBlue

Automate CloudBlue from your terminal, your code and your AI agent.

| Project | What you get |
|---|---|
| ⌨️ [connect-cli](https://github.com/cloudblue/connect-cli) | Connect in your terminal: edit products in Excel and sync them back, run reports, start new extensions.<br>`brew install cloudblue/connect/connect-cli` |
| 🐍 [connect-python-openapi-client](https://github.com/cloudblue/connect-python-openapi-client) | Fluent, REPL-friendly Python client for the Connect API. Sync or async, with RQL queries built in. |
| 🧩 [connect-eaas-core](https://github.com/cloudblue/connect-eaas-core) | Ship Connect extensions in plain Python: events, schedules, web apps and transformations. They run on [connect-extension-runner](https://github.com/cloudblue/connect-extension-runner). |
| 📊 [connect-reports-core](https://github.com/cloudblue/connect-reports-core) | Custom reports in Python, delivered as Excel, CSV, JSON, PDF or your own Jinja template. They run on [connect-reports-runner](https://github.com/cloudblue/connect-reports-runner). |
| 🤖 [agent-skills](https://github.com/cloudblue/agent-skills) | Ready-made skills that let your AI agent handle products, pricing, listings, fulfilment and helpdesk through the Connect MCP server. |
