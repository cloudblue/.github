# cloudblue/.github

Default community files for the [cloudblue](https://github.com/cloudblue) organization.

| File | What it does |
|---|---|
| `profile/README.md` | The front page shown on https://github.com/cloudblue |
| `profile/cloudblue-logo.svg`, `profile/cloudblue-logo-dark.svg` | The logo on the front page, for light and dark themes |
| `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md` | Used by every repository that doesn't have its own copy |
| `ISSUE_TEMPLATE/` | Issue forms for every repository that has no issue templates of its own. A repository with its own `ISSUE_TEMPLATE` folder uses only its own |
| `pull_request_template.md` | The default pull request description |

A licence can't be shared this way: every repository keeps its own `LICENSE` file.

To change any of these files, open a pull request here.
